Standalone: Pre-Flight Clarification (استكمال النواقص)
======================================================================
Endpoint: POST /api/ClarifyFacts/evaluate
Location: `wwwroot/prompts/Global/`

| File                | Purpose                                                      |
|---------------------|--------------------------------------------------------------|
| clarify-facts.txt   | Evaluate case facts for gaps, return 3–7 questions with MCQ  |

NOTE: This is a modal-based checkpoint, NOT a pipeline step.
      It runs before any workflow starts. Returns questions with
      3 suggested answers each (frontend adds a 4th "custom input" option).
      If facts are complete, returns an empty questions array.

Notes on Pipeline Registry
======================================================================
To add a new pipeline:
1. Register it in Lawyer.Application/Services/Workflows/PipelineRegistry.cs
2. Add the corresponding AiStepType enum values in Lawyer.Core/Enum/AiStepType.cs
3. Create the prompt files under wwwroot/prompts/<folder>/
4. Add strongly-typed output DTOs in StepOutputDtos.cs
5. Register case branches in StepOutputSchemas.Normalize()
6. Append the new mapping here for developer reference
